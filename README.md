# University-Enrollment-Management-System

A Java-based console application developed to manage university enrollments using Object-Oriented Programming (OOP) and core data structures.

## Features

* Student and course management
* Course enrollment system
* Validation and enrollment constraints
* Sorting functionality
* Undo/Redo operations using Stacks

## Technologies Used

* Java
* OOP
* Linked Lists
* Stacks
* Console I/O

## Purpose

This project was developed to strengthen problem-solving, backend logic, and data structure implementation skills.
